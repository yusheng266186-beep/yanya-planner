## 项目定位

“研芽”服务于西华师范大学学科教学（语文）方向的 30 天基础夯实计划。它把“今天要学什么”拆成可执行、可勾选、可复盘的步骤，适合手机使用，也可以添加到安卓主屏幕作为 PWA 使用。

项目强调稳定交付，而不是一次性堆满任务：

- 每天有明确的学习任务；
- 每天有可检查的完成标准；
- 每周有轻量复盘；
- 低状态时也可以保留最小行动；
- 所有记录保存在使用者自己的浏览器中。

## 核心功能

### 首页 Dashboard

- 今日进度环；
- 连续打卡天数；
- 距计划收官的倒计时；
- 已完成天数和番茄钟统计；
- 每日鼓励语；
- 今日任务和快捷入口。

### 30天计划

- 按阶段组织完整学习路线；
- 点击日期查看详细任务；
- 每日包含学习内容、验收标准和提示；
- 可以标记当天完成；
- 适合按自己的节奏补做或调整。

### 今日打卡

- 按 13 个时间段拆分任务；
- 实时显示完成进度；
- 全部完成后给出鼓励反馈；
- 使用本地记录保存每日状态。

### 周复盘

- 5 周自查清单；
- 周日轻量复盘模板；
- 五周周报记录；
- 帮助从“完成了多少”回到“哪里需要调整”。

### 专注与情绪

- 25 分钟专注、5 分钟休息的番茄钟；
- 番茄次数累计；
- 5 档心情日记；
- 支持文字记录和历史回看。

### 我的

- 学习方法库；
- 每日时间表；
- 四科目标；
- 8月衔接内容；
- 资料来源与项目说明；
- 重置本地记录。

## 使用方式

### 手机在线使用

1. 用 Android Chrome 或 Edge 打开 Pages 地址；
2. 打开浏览器菜单；
3. 选择“添加到主屏幕”；
4. 点击桌面上的“研芽”图标即可全屏使用。

### 电脑使用

直接访问网页即可。第一次打开时建议让资源完整加载。

### 本地预览

为了测试 Service Worker 和 PWA 行为，建议使用 HTTP 静态服务器：

    python -m http.server 8080

然后打开：

    http://localhost:8080/

直接双击 index.html 也可以阅读，但离线缓存、安装到主屏幕等 PWA 能力通常需要 HTTP 或 HTTPS 环境。

## 数据与隐私

- 学习打卡、番茄钟、心情日记等数据保存在本机浏览器；
- 项目不要求注册账号；
- 项目不提供云端同步；
- 更换浏览器、清除站点数据或使用无痕模式，可能看不到原来的记录；
- 不要在心情日记中记录不适合公开的隐私内容，尤其不要把个人隐私提交到仓库文件中。

## 技术实现

- 原生 HTML、CSS、JavaScript；
- PWA manifest；
- Service Worker；
- localStorage 本地持久化；
- 响应式移动端布局；
- GitHub Pages 静态托管。

项目没有 npm 构建步骤，适合直接复制、部署和在手机上使用。

## 修改学习计划

如果需要改日期或任务，建议：

1. 先备份 assets/ 中的原始数据文件；
2. 统一修改计划日期、阶段标题和每日任务；
3. 同步修改首页倒计时和完成统计逻辑；
4. 检查 30 天、打卡、复盘三个入口是否使用同一套日期；
5. 更新 Service Worker 缓存版本，避免旧手机继续使用旧资源；
6. 在手机上重新测试添加到主屏幕后的显示效果。
